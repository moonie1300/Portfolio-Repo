# Hannah John - Portfolio

My personal portfolio website showcasing my work in software engineering and robotics.

🔗 **View Live**: [hannah-john-02.vercel.app](https://hannah-john-02.vercel.app)

> **Note**: This is a personal portfolio. Please do not fork or use the content/design for your own purposes.

## Tech Stack

- **React 19** - Modern component architecture
- **TypeScript 5.7** - Type-safe development
- **Vite 8** - Lightning-fast build tooling
- **Tailwind CSS v4** - Custom styling system with utility classes
- **Vercel** - Continuous deployment

## Features

- **Fully Responsive** - Mobile-first design with hamburger navigation
- **Scrapbook Aesthetic** - Hand-crafted UI with tape elements, tilted cards, and floating stickers
- **Custom Animations** - Smooth scrolling, hover effects, and animated ticker
- **Performance Optimized** - Fast load times with optimized images and code splitting
- **Custom Components** - Reusable stickers, project cards, and decorative SVGs

## Future Features

- **PopUps** - set up pop ups for selected work to display more information
- **Scrapbook** - Scrapebook style for interactivity
- **Dark Mode** - Toggle between light and dark themes
- **Project Demos** - Embedded videos and interactive demos
- **Analytics Dashboard** - Track visitor engagement
- **Theme Customization** - Allow visitors to choose color schemes
- **Contact Form** - Direct messaging with form validation
- **Certifications** - Display professional certifications and achievements
- **PWA Support** - Installable progressive web app
- **i18n** - Multi-language support

## Design

Custom color palette: warm, earthy tones (parchment, sage, rose, charcoal) with a scrapbook-inspired layout featuring inline React styles for precise component control.
